Release notes

What's new in Axia Security, release by release.

This page lists every Axia Security release, newest first.

v3.1.0 — 3 November 2026

New

  • Automatic directory sync. Axia keeps your user directory up to date from Microsoft Entra ID and Google Workspace. You no longer have to upload it by hand.
  • Slack files. Axia now reads the content of files shared in the Slack channels you connect, not just the messages.
  • Faster email analysis. A dedicated classifier checks each email first, so routine emails are released sooner. A small sample of those emails still goes through the full analysis, as a quality check.

Improved

  • Case pages are easier to scan. The page opens collapsed, and the evidence view lists findings first, with long text and email threads collapsed.
  • For every email client (Outlook, Gmail and others), a person's reply is shown separately from the quoted thread below it.
  • The case timeline shows who assigned a case and who owned it before. Status changes show the old and the new status, including for bulk changes.
  • Every connector on the Connect page links to its setup guide in the Help Center.

Fixed

  • After Slack was connected, the Connect page sometimes failed to load.
  • The Outlook connector kept logging errors for mailboxes that don't exist.
  • In Slack cases, the person involved is now the first person to post, ordered by posting time.

Security

  • Updated third-party libraries to patched versions.

Self-hosted: install or upgrade with Helm chart version 3.1.0. See the Deployment guide.

v3.0.0 — 28 October 2026

New

  • Slack connector. Connect Slack from the Connect page and choose which channels Axia reads. Slack messages show up in cases like email does. See the Slack setup guide.
  • Sign in with JumpCloud. Users can sign in with JumpCloud SSO. New users are provisioned automatically, and the Users page shows how each user signs in.
  • Manage policies from Intel. Administrators can ask Intel which policies are active, and have Intel propose a new policy, which is added once they confirm it. The same tools are available from the Axia Security MCP server in Claude Desktop. The policy audit log shows where each change was made.
  • Connect an AI agent. When you're already signed in to the dashboard, you can connect an AI agent to Axia without signing in again. The agent sign-in page also offers Sign in with your company account.
  • Role owners from the organization file. A new axia_role column (hr, legal or ciso) sets each role's owner. It's validated when you upload the file.
  • Replies on Google Workspace engagement mailboxes. Axia reads replies sent to an engagement mailbox in Google Workspace.

Improved

  • Self-hosted installations can set up judgment and engagement entirely from the Connect page, without editing configuration files.
  • When your session expires and you sign in again, you're taken back to the page you were on.

Fixed

  • The runtime configuration editor wouldn't save while Azure DevOps static fields were configured.

Security

  • Stronger passwords. One strong password rule now applies wherever a password is set, including the break-glass administrator. User forms list the rules and refuse weak passwords. Users whose password doesn't meet the rules are asked to choose a new one when they next sign in. Making a user an administrator requires a new, administrator-strength password.
  • Changing a user's credentials signs out their active sessions.
  • Uploaded Intel and guidance documents are checked for file type, content, malicious content and size.
  • Sign-in codes are kept out of the logs.
  • Resolved all critical and high severity issues in dependencies and source code, and updated third-party libraries.

Self-hosted: Helm charts are now versioned with the product (3.0.0) and signed with cosign. See the Deployment guide.

v0.97.0 — 21 October 2026

New

  • Refreshed look. A redesigned sign-in page, and a new sidebar with grouped sections that collapses. The light/dark theme switch and your account menu are now in the sidebar.
  • Claude Code and Cursor connectors. Connect AI coding agents from the Connect page, to analyse prompts for sensitive data.
  • Connector permissions you can see. The Connect page shows which permissions each connector was granted, and Test checks them. Each connector links to its setup guide.
  • Engagement mailbox. Choose the mailbox Axia uses to contact people, from the Microsoft 365 or Google Workspace connector card.
  • Replies and decisions on cases. The case page shows replies in the engagement thread, Axia's proposal to close a case, who closed the case, and a Reopen option.
  • Releasing held messages. Release a held email from the case page. The case shows each release request and its outcome.
  • Revoke share link. Revoke a risky sharing link directly from the case's actions.
  • Ticketing. Create Ticket and Send to Reviewer are now in the case's Actions card. Tickets include the full analysis and suggested actions. Azure DevOps work items can be filed under a configured parent item.
  • Act. Built-in outreach actions are available. A case can now be closed automatically when the person involved confirms.

Improved

  • Case pages are easier to read: analyses start collapsed, the timeline entries fold, and quoted email history is hidden.
  • The Connect page is shown only to administrators.
  • Clearer error messages when testing Google Workspace and Microsoft 365 connections.

Security

  • Updated third-party libraries and operating-system packages to patched versions.

v0.96.0 — 21 October 2026

  • Self-hosted installation. Self-hosted deployments now install with Helm. See the Deployment guide.

How we communicate changes

  • Every release has a version number and appears on this page on the day it's released.
  • Planned maintenance is announced in advance. See Support.
